# 美容室シャンプー ウェブサイト

美容室シャンプーの公式ウェブサイトです。

## 概要

このプロジェクトは、静岡県三島市にある美容室「美容室シャンプー」の公式ホームページを構築することを目的としています。ダメージレスとエイジングケアを最優先にしたサロンのコンセプトを反映し、髪を守り、心を癒やす空間を表現するウェブサイトです。

## 技術スタック

- **HTML5** - セマンティックなマークアップ
- **CSS3** - カスタムプロパティ（CSS変数）を使用したモダンなスタイリング
- **JavaScript (Vanilla)** - インタラクティブな機能の実装
- **Google Fonts** - Noto Serif JP / Noto Sans JP フォント

### コンセプト

- **ダメージレス（傷ませないこと）** - すべての施術において髪を守る
- **エイジングケア（治す視点）** - エイジング毛への治療発想のケア
- **素材美の回復** - 本来のツヤとハリを取り戻す
- **精神的な癒やし** - 静かな呼吸、荷物を下ろす場所

## セットアップ・実行方法

このプロジェクトは静的HTMLサイトのため、特別なビルドツールやパッケージマネージャーは不要です。

### 方法1: 直接ブラウザで開く（最も簡単）

1. `index.html` をダブルクリックしてブラウザで開く
2. または、ブラウザの「ファイルを開く」から `index.html` を選択

**注意**: この方法では一部の機能（CORS制限など）が正しく動作しない場合があります。

### 方法2: ローカルサーバーを使用（推奨）

ローカルサーバーを使用することで、すべての機能が正しく動作します。

#### Python 3を使用する場合

```bash
# プロジェクトディレクトリに移動
cd shanpoo

# ローカルサーバーを起動
python -m http.server 8000
```

ブラウザで `http://localhost:8000` にアクセス

#### Node.jsを使用する場合

```bash
# プロジェクトディレクトリに移動
cd shanpoo

# http-serverをインストール（初回のみ）
npm install -g http-server

# サーバーを起動
http-server
```

ブラウザで表示されたURL（通常は `http://localhost:8080`）にアクセス

#### VS CodeのLive Server拡張機能を使用する場合

1. VS Codeに「Live Server」拡張機能をインストール
2. `index.html` を開く
3. 右クリック → 「Open with Live Server」を選択

自動的にブラウザが開き、ファイル変更時に自動リロードされます。

## カスタマイズ・開発

### 店舗情報の更新

`access.html` の以下の部分を実際の情報に更新してください：

- 所在地の詳細住所
- 営業時間
- 定休日
- お問い合わせ方法（電話番号、メールアドレスなど）

### 料金の更新

`menu.html` の料金表を実際の料金に更新してください。現在は「要相談」となっています。

### CSS変数のカスタマイズ

`css/style.css` の `:root` セクションでカラーパレットやスペーシングを変更できます：

```css
:root {
    --color-primary: #8B9A7A; /* グリーン系 */
    --color-secondary: #D4C4B0; /* ベージュ系 */
    --color-accent: #E8E4D8; /* 淡い光の色 */
    /* その他の変数... */
}
```

### JavaScript機能の拡張

`js/main.js` には以下の機能が実装されています：
- モバイルメニューのトグル機能
- スムーススクロール
- スクロール時のナビゲーションバーのスタイル変更

新しい機能を追加する場合は、このファイルを編集してください。

## Web公開時のアップロードファイル

このプロジェクトをWebサーバーに公開する際は、以下のファイルとフォルダをアップロードしてください。

### 必須ファイル・フォルダ

```
shanpoo/
├── index.html          # トップページ（必須）
├── concept.html        # コンセプトページ
├── menu.html          # メニュー・料金ページ
├── process.html       # こだわり・技術ページ

├── css/
│   └── style.css      # メインスタイルシート（必須）
└── js/
    └── main.js        # メインJavaScript（必須）
```

### アップロード不要なファイル

以下のファイルは開発用のため、Webサーバーにはアップロードする必要はありません：

- `README.md` - 開発用ドキュメント
- `.gitignore` - Git管理用ファイル

### アップロード時の注意点

1. **フォルダ構造の保持**: `css/` と `js/` フォルダの構造をそのまま維持してください
2. **ファイル名の大文字小文字**: サーバーによっては大文字小文字を区別するため、ファイル名は正確に一致させてください
3. **ルートディレクトリ**: 通常は `index.html` をサーバーのルートディレクトリ（`public_html/` や `www/` など）に配置します
4. **パーミッション**: ファイルの読み取り権限が適切に設定されているか確認してください（通常は644）

### 一般的なアップロード方法

#### FTP/SFTPを使用する場合
1. FTPクライアント（FileZilla、Cyberduckなど）を使用
2. サーバーのルートディレクトリに接続
3. 上記の必須ファイルとフォルダをアップロード

#### cPanelなどのコントロールパネルを使用する場合
1. ファイルマネージャーを開く
2. `public_html` または `www` フォルダに移動
3. ファイルとフォルダをアップロード

#### Gitを使用する場合
```bash
# サーバーにGitがインストールされている場合
git clone <リポジトリURL>
# または
git pull
```

### 動作確認

アップロード後、以下のURLで各ページが正しく表示されるか確認してください：

- `https://yourdomain.com/` または `https://yourdomain.com/index.html`
- `https://yourdomain.com/concept.html`
- `https://yourdomain.com/menu.html`
- `https://yourdomain.com/process.html`
- `https://yourdomain.com/access.html`
